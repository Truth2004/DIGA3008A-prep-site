# Zombie Apocalypse Survival Preparation Site

Welcome to the **Zombie Apocalypse Survival Preparation Site**! This project is a themed web application designed to guide users on disaster preparedness through the fun and engaging lens of a zombie apocalypse scenario. 

## Features

*   **Thematic Design:** Engaging zombie survival aesthetics to capture the apocalyptic mood.
*   **Survival Statistics:** A stylized dashboard tracking "Zombies Killed," "Survivors Saved," and "Shots Fired."
*   **Weather API Integration:** Retrieves real-time weather data for a specified location to return custom survival conditions and environmental tips based on the current temperature and climate.
*   **GSAP Scroll Animations:** Smooth, dynamic scroll-triggered animations implemented with GSAP to enhance the user experience and bring the apocalyptic content to life.
*   **Form Validation:** Robust front-end form validation to ensure user inputs are accurate and secure before submission.
*   **Survival Kits:** Detailed breakdowns of essential equipment for different scenarios, including Individual, Group, and Long-run kits.
*   **Guides & Research:** Essential survival tactics and behavioral research on the living dead.
*   **Lore:** Engaging backstory explaining the origins and spread of the worldwide infection.
